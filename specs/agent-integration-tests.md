# Интеграционные тест-кейсы ACP-агента

Результаты Claude зафиксированы **2026-11-02** на VM: форк
`angrybender/acp-wrapper` commit `971c9ea`, Claude ACP 0.96.0,
Claude Agent SDK 0.3.310, ACP v1, `bypassPermissions`, RouterAI,
`anthropic/claude-sonnet-4.6`. Полные версии, доказательства и ограничения —
таблица ниже (исторический прогон Claude сохранён без переоценки).

Codex проверен **2026-11-02**: codex-acp 2.2.2 с новым backend форка,
Codex CLI 0.163.0, Node.js 22.23.2, RouterAI Responses API,
`openai/gpt-6-luna`, Linux VM из конфигурации оркестратора.
Подробности и ограничения — [codex-support.md](codex-support.md).

Для повторной проверки использовать отдельные cwd, CLAUDE_CONFIG_DIR и
тестовые задачи вне рабочей БД/очереди. SSH-параметры читать из конфигурации
оркестратора, ключ провайдера передавать отдельно и не записывать в отчёт.
Продолжать читать события между RPC. Проверять файлы и реальные процессы,
включая отдельные группы потомков; одного end_turn или stopped недостаточно.
После выхода ACP допускать до 5 с на завершение SDK-процессов. После проверки
удалять только собственные процессы, каталоги, ключи и тестовые логи.

«Пройден» относится к критерию конкретной строки. Для отрицательного сценария
ошибка без ложного успеха может быть ожидаемым результатом. «Частично» означает,
что защитное поведение подтверждено, но дополнительная гарантия не получена.
