## Layout web application

**Основное меню web-app**

```
[ Board ] [ Archive ] [ Settings ] [ Background tasks ]
```

**Общие требования**

- Не добавляй на страницы приложения декоративные или текстовые заголовки раздела, включая основной заголовок страницы и подзаголовок/eyebrow, если такой элемент явно не указан в спецификации или эталонном макете конкретной страницы.
- Никогда не добавляй подзаголовок на странице
- Кнопки всегда выровнены по правому краю layout родителького контейнера кнопки
- Операции сохранения/обновления после нажатия на соотвествующую кнопку, которые требуют сетевых вызовов за пределами приложения должны сопровождаться spinner с блокировкой кнопки до успешного (или нет) завершения операции

### Spinner

Spinner используется для кнопок, запускающих сетевые операции. Перед началом операции вызовите `window.spinner.start(button)`, а после завершения — `window.spinner.stop(button)` в блоке `finally`.

В состоянии загрузки виджет:
- блокирует кнопку через `disabled`;
- блокирует все `input`, `select`, `textarea` и `button` внутри связанной формы;
- помечает связанную форму атрибутом `data-spinner-active="true"` и `aria-busy="true"`;
- игнорирует повторный submit связанной формы до завершения текущей операции;
- добавляет атрибут `aria-busy="true"`;
- показывает анимированный индикатор и временный текст действия;
- восстанавливает исходный текст и доступность кнопки после завершения операции, включая ошибку.

Стили и логика виджета подключаются глобально из `static/css/spinner.css` и `static/js/spinner.js`.

### Toast

Toast используется для кратких уведомлений о результате действий пользователя. Для показа уведомления вызовите:

```js
window.showToast(message, options)
```

Параметры `options`:
- `type: "error"` — отображает ошибку, устанавливает роль `alert` и применяет состояние ошибки;
- без `type` или с другим значением — обычное уведомление с ролью `status`;
- `duration` — время отображения в миллисекундах, по умолчанию `3000`.

Виджет:
- создаёт общий регион уведомлений с `aria-live="polite"` и `aria-atomic="true"`;
- размещает уведомления в правом нижнем углу экрана;
- показывает уведомления с анимацией появления и скрытия;
- удаляет уведомление из DOM после завершения анимации скрытия;
- не блокирует взаимодействие пользователя со страницей.

Стили и логика виджета подключаются глобально из `static/css/toast.css` и `static/js/toast.js`.


### UI цикла задачи

Проверка пути Init в Settings Tasks использует общий Spinner и Toast. Новые поля располагаются в существующей двухколоночной форме без заголовка страницы. Board использует существующий индикатор с метками In progress / Init / Agent; чат показывает системную ошибку Init как текст. Поля и Save — [settings.md](settings.md), индикатор — [board.md](board.md), сообщения — [task-chat.md](task-chat.md), цикл выполнения — [agent.md](agent.md).
