## Техническая спецификация

### Стэк

- Python3.12+
- FastAPI, в том числе для отдачи статики
- SQlite в качестве СУБД

### Тестовые зависимости

- TestClient использует `httpx2>=2.12,<3.0` с `starlette>=1.6.0,<2.0` и `fastapi>=0.141.1,<1.0`.
- Временное ограничение `anyio>=4.14,<4.15` необходимо из-за обращения Starlette 1.6.0 к `anyio.abc.BlockingPortal`. Это ограничение совместимости, а не исправление устаревшего API внутри Starlette; пересмотреть после выхода её исправленной версии.
- Контрольный прогон: `PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=. python3 -m pytest -q -p no:cacheprovider -W error tests`. Предупреждения не подавлять.

### Жизненный цикл приложения

- Инициализация SQLite выполняется до обработки запросов через `FastAPI(lifespan=...)`; устаревший `on_event("startup")` не используется.
- Повторный запуск жизненного цикла безопасен: существующие таблицы и данные сохраняются. Проверка — `tests/test_app.py::test_lifespan_initializes_database_without_deprecation`.

### Real-time Board

- Транспорт — SSE: `GET /api/board/events`, `text/event-stream`, событие `board` с актуальным списком задач. Детальные требования — [board.md](board.md).
- Генератор событий находится в `board_events.py`; блокирующее чтение SQLite выполняется в thread pool, соединение закрывается после каждого согласованного снимка. Проверяются изменения общей БД, а не только запросы к web-процессу.
- Клиент подключения — `static/js/board-live.js`, обычный script без `import` и сборки, подключается только в шаблоне Board перед `board.js`.
