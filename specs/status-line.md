### Строка статуса Board

Реализованные требования (уточнение исходного черновика).

```text
(o) Codex limits remaining (reset at, UTC): weekly N% (Y-m-d H:i:s)     [ Clear DB ] [ Agent Recovery ] [ New task + ]
(o) Claude limits remaining (reset at, UTC): weekly N% (Y-m-d H:i:s) / 5-hours M% (Y-m-d H:i:s)
```

- Строка находится слева от существующих кнопок Board. На узких экранах текст и кнопки переносятся без переполнения; кнопки сохраняют выравнивание вправо. Заголовков страницы нет.
- Кружок синий `#4389e7`, если аутентификация SSH успешна; красный `#f15b5b`, если подключения нет. Начальное состояние и ошибка обращения к приложению — серый, статус неизвестен. Доступность обозначается также accessible name и tooltip, а не только цветом.
- Показывается агент из `agent.shell`: прямой `codex`/`claude` (в том числе абсолютный путь) либо `acp-wrapper <путь-к-cli> ...`. Произвольные shell-программы не выполняются для определения агента. Неподдерживаемый агент сохраняет проверку SSH, без лимитов.
- Проценты обозначают оставшуюся долю подписки: `100 − used_percent`. Например, 3% использовано → 97% осталось, 0% → 100%, 100% → 0%. Подпись — `limits remaining`; выводить до двух знаков после десятичной точки без незначащих нулей и артефактов вычислений с плавающей точкой. Codex: только недельное окно (10080 минут). Claude: недельное и пятичасовое окна. Каждое окно имеет собственную дату сброса в UTC до секунд.
- Отсутствующие, некорректные и истёкшие окна скрываются независимо. Если получить лимиты нельзя, отображается только кружок SSH. При недоступном SSH любые лимиты скрыты, прежние данные не сохраняются на экране.
- Обновление при открытии Board и каждые 60 секунд, без параллельных запросов одной страницы. Запрос ограничен 45 секундами; ошибка этого фонового запроса не вызывает дополнительный Toast поверх уведомления SSE; после возврата из browser back/forward cache опрос возобновляется. Скрипт и стили подключены только на Board, без import и сборки.

### Получение данных

- `GET /api/agent/status` возвращает только `{reachable, agent, limits: [{name, used_percent, resets_at}]}`, `Cache-Control: no-store`. `used_percent` содержит расход провайдера; клиент вычисляет остаток для отображения. Ошибка SSH/провайдера — штатный ответ 200 с соответствующим состоянием и пустыми лимитами.
- `remote_limits.py` получает согласованный снимок Remote server и Agent через Config, проверяет SSH с известными host keys и RejectPolicy. Приоритет ключа над паролем, SSH agent и подбор ключей отключены. Connection/auth/banner timeout — по 5 секунд, выполнение helper — до 20 секунд после отправки. Размер ответа ограничен 64 КиБ; SSH-ресурсы закрываются при любом результате.
- Минутный кэш разделяется запросами одного web-процесса под lock; изменение настроек инвалидирует его. Несколько web-процессов имеют отдельные кэши. Секреты не входят в публичный ответ или журнал диагностики.
- `remote_limits_probe.py` передаётся через stdin `python3 -` на удалённую POSIX-машину; временные файлы не создаются. Требуется удалённый Python 3. Credential и исходные ответы провайдера остаются на удалённой стороне; наружу передаются только поля окон.
- Codex: используется CLI из настроенной команды wrapper, например `/home/user/.local/bin/acp-wrapper /usr/bin/codex --yolo` → `/usr/bin/codex app-server`. Выполняются только `initialize`, `initialized`, `account/rateLimits/read`; ACP-сессия, thread и prompt модели не создаются. Процесс имеет deadline 15 секунд и завершается с ожиданием, при необходимости TERM/KILL собственной группы. Источник протокола: [Codex App Server](https://learn.chatgpt.com/docs/app-server). CLI-флаги выполнения задачи (`--yolo` и т.п.) в проверку лимитов не переносятся; используется обычная конфигурация аккаунта SSH-пользователя.
- Claude: чтение OAuth-подписки через `https://api.anthropic.com/api/oauth/usage` с токеном из `$CLAUDE_CONFIG_DIR/.credentials.json` либо `~/.claude/.credentials.json`, timeout 12 секунд. Поля `seven_day.utilization/resets_at` и `five_hour.utilization/resets_at` нормализуются в общий формат. Endpoint не является гарантированным публичным API: изменение схемы, отсутствие OAuth, API-key/provider login, Keychain без файла, HTTP 401/429 и сетевые ошибки скрывают лимиты без изменения SSH-статуса. Авторизация/refresh и настройки Claude не изменяются. Shell-префиксы окружения из `agent.shell` не исполняются; используется окружение SSH-пользователя.
